# Lotus Members — Native Android

Fully native Android app (not a WebView shell) matching the Lotus members portal.

## Features
- Same dark glass UI as the website
- Live status every ~3.5s without full-screen reload
- Online players + full offline roster
- **Open Minecraft · Add Lotus** via `minecraft://?addExternalServer=…`
- Start server (members only)
- Share join link / copy domain
- Pull-to-refresh, haptics

## Build
Actions → Build Lotus APK → download artifact.
